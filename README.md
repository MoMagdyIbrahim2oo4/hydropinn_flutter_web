# HydroPINN — منصة التنبؤ بحركة المياه الجوفية (نسخة Flutter Web)

تحويل كامل ومطابق 1:1 لمنصة **HydroPINN (الإصدار 2.4)** من HTML/CSS/JS إلى تطبيق **Flutter Web** متكامل يدعم العربية (RTL) والإنجليزية (LTR)، الثيم الليلي والنهاري، والرسوم البيانية العلمية المخصصة عبر `CustomPainter`.

## المميزات المحولة بالكامل
1. **الشاشات الستة (6 Views)**:
   - **نظرة عامة (`Overview`)**: المؤشرات الرئيسية الأربعة، الخريطة الحرارية المصغرة للمنسوب، منحنى تطور المنسوب عند البئر، وتصنيف المخاطر مع التوصية التشغيلية.
   - **استكشاف الخزان (`Explore`)**: خريطة حرارية تفاعلية بدقة 50×50 مع استيفاء ثنائي الخطوط (Bilinear Interpolation)، خطوط تساوي المنسوب (Contours)، فحص أي خلية بالنقر أو التمرير، تشغيل/إيقاف الحركة الزمنية، ومنحنيات المقاطع العرضية (شرق–غرب وشمال–جنوب).
   - **مقارنة السيناريوهات (`Compare`)**: مقارنة جنباً إلى جنب بين أي سيناريوهين (أ، ب) مع خريطة الفارق المكاني المعمّمة بفلتر 3×3، جدول المقارنة التفصيلي، ومنحنى مسار البئرين عبر 30 يوماً.
   - **المخاطر والقرار (`Risk & Decision`)**: عداد المخاطر نصف الدائري، أداة البحث العكسي عن القرار (`Goal Seek`) لحساب أقصى معدل ضخ آمن، بطاقات التوصيات، وخريطة مصر التفاعلية للأحواض الجوفية الأربعة (غرب الدلتا، غرب المنيا، الفرافرة، توشكى).
   - **دقة النموذج (`Model Accuracy`)**: مقارنة سرعة ودقة نموذج HydroPINN مقابل المحاكي العددي `MODFLOW-2005`، مصفوفة الخطأ الكاملة (10 سيناريوهات × 33 خطوة زمنية)، ومنحنى RMSE عبر الزمن.
   - **البيانات والتصدير (`Data & Export`)**: جدول سيناريوهات المحاكاة العشرة مع التصفير والفرز، تصدير CSV، حفظ السيناريوهات، ومواصفات عقد الـ REST API الخاص بـ `.NET 8`.
2. **الأدوات التفاعلية**:
   - **لوحة الأوامر السريعة (`Command Palette`)**: تعمل بالضغط على `Ctrl+K` أو زر البحث العلوي.
   - **الجولة التعريفية التفاعلية (`Guided Tour`)**: من 7 خطوات متتابعة.
   - **درج السيناريوهات المحفوظة (`Saved Scenarios Drawer`)**: لحفظ ومقارنة واسترجاع الإعدادات.
   - **اختصارات لوحة المفاتيح**: `ArrowLeft` / `ArrowRight` للتنقل الزمني، `Space` لتشغيل/إيقاف العرض الزمني، `Ctrl+K` للبحث، `Escape` لإغلاق النوافذ.

## هيكل المشروع
```text
hydropinn_flutter_web/
├── pubspec.yaml
├── analysis_options.yaml
├── assets/
│   └── data/
│       └── hydro_data.json       # بيانات MODFLOW-2005 و PINN الكاملة (617 KB)
├── web/
│   ├── index.html
│   └── manifest.json
└── lib/
    ├── main.dart                 # نقطة الدخول الرئيسية والتطبيق المتكامل
    ├── core/
    │   ├── theme/
    │   │   └── app_theme.dart    # ألوان وثيمات الوضع الليلي والنهاري
    │   └── localization/
    │       └── app_localizations.dart # قاموس الترجمة الكامل (AR / EN)
    ├── models/
    │   └── hydro_models.dart     # نماذج البيانات والسيناريوهات والمقاييس
    ├── state/
    │   └── hydro_controller.dart # إدارة الحالة والعمليات الحسابية (Goal Seek, Grids)
    └── widgets/
        └── custom_painters.dart  # محرك الرسوم العلمية (Heatmap, Line, Bar, Matrix, Gauge, Egypt Map)
```

## طريقة التشغيل على جهازك
1. فك ضغط الملف `hydropinn_flutter_web.zip`.
2. افتح المجلد في **VS Code** أو **Android Studio**.
3. نفّذ الأوامر التالية في الطرفية (PowerShell / Terminal):
```bash
flutter pub get
flutter run -d chrome
```
4. لبناء نسخة الإنتاج (Production Release):
```bash
flutter build web --release
```
